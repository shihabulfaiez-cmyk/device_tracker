# IT Device Tracker

A web application built with PHP and MySQL to manage network devices.

## Login Credentials
* **Email:** admin@it-services.com
* **Password:** password

## How to Run
1. Place the `device_tracker` folder inside `C:\xampp\htdocs\`.
2. Start **Apache** and **MySQL** in XAMPP.
3. Import the `device_tracker` database in phpMyAdmin (`http://localhost/phpmyadmin`).
4. Open `http://localhost/device_tracker/index.php` in your browser.
